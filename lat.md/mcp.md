# Model Context Protocol

Bug Killer provides Model Context Protocol (MCP) server endpoints for AI agent pair-programming.

The MCP server exposes secure security inspection and scanning capabilities over stdio transport.

## Stdio Protocol Server

The MCP server communicates using JSON-RPC messages over standard input and output channels.

Server request dispatch is handled by [[src/mcp/server.rs#McpServer]] using structured payloads from [[src/mcp/protocol.rs#JsonRpcRequest]] and [[src/mcp/protocol.rs#JsonRpcResponse]].

Research execution and verification endpoints currently return `NOT_RUN` or `verified: false` because no execution backend or proof store is wired to these handlers. A plan is not evidence of execution.

## Read-Only Security Boundary

By default, MCP server connections execute in read-only mode to prevent unapproved agent mutations.

Privileged healing operations cannot be executed through unauthenticated MCP calls without supervised approvals.

## Client Host Configuration

Host configuration generators produce ready-to-use MCP configuration blocks for major AI coding agents.

Configuration output for Claude Code, Codex, and Gemini CLI is generated by [[src/mcp/host_config.rs#HostConfigGenerator]].
